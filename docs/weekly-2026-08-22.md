## What happened this week

- **Registry crossed 900**: the dsh-subscribe marketplace registry now tracks
  **908 plugins** (up from ~554 in Week 1). Verified subset: 21.
- **Awesome-list seats grew**: 10 zoahdev entries merged into
  `0xsline/awesome-deepseek-harness` (#283, #290–296, #359 — incl. dsh-zh,
  dsh-code, dsh-vision); `awesome-dsh-plugin` merged the doctor entry, with
  poison-guard / artifacts / browser-use / firecrawl in the repo's 1-day gate.
- **dsh-doctor/v1 contract converged across 5 implementations**: zoahdev
  `dsh-plugin-doctor`, `moonquake2004/dsh-doctor`, `ciceroyang/dsh-doctor`,
  `sjh9714/dsh-win32`, and `worm-ai/dsh-diagnose` all emit the same
  `{schema: dsh-doctor/v1, ok, checks}` envelope; a check-lifecycle draft
  (`docs/check-lifecycle.md`) and vocabulary r4 freeze candidate are public.
- **RFCs**: #2486 (42 cherry-pick-ready upstream patches), #1846 (community
  plugin registry contract v2 + first-class `dsh plugin check` / `dsh doctor`).
- **dsh-compass reached official master**: `github:Happy2Git/dsh-compass` now
  installs on a clean upstream master build (v0.13–0.15; /dir + /git + context
  tabs, panel-state persistence, event-driven context badges).
- **Subagent steering proved feasible**: a client plugin demonstrated the API
  layer does not reject subagent steering (only the InputBar gates it) — RFC
  draft for a `subagent/steer` session event offered, aligned with #1517.
- **Engagement**: 14 verified comments/replies by zoahdev in official
  Discussions (5 acceptance requests, 7 verified answers on install/TUI/413/
  workspace/minimal/third-party-token questions, 2 follow-ups to author
  mentions).
